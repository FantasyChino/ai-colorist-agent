# AI Colorist v1.0.0

First public release: host-model photographic judgment with local MCP tools and
the existing OpenCV pipeline. Ordinary use requires no training or GPT API key.

- Six MCP tools: connection test, catalog listing, strength preparation, grading,
  optional pixel statistics and optional source-conditioned reference fitting.
- Eighteen bundled creative LUTs: ten original analytic recipes, six Pat David
  approximations (CC-BY-SA-4.0), and two LUMIX original looks (upstream MIT).
- Four approved before/after photo showcases and their photo-specific example
  CUBEs. These demonstrate individually authored grades, not universal presets
  or a pretrained neural model. Photograph copyright remains separate.
- Portable setup/configuration, four skills, documented executable controls and
  extension points for future dehazing and masked grading. Those features are
  not implemented in v1.0.0.

Validation: 37 unit tests passed, both real stdio MCP protocol checks passed,
and plugin/MCP manifests matched the Agent Plugins 1.0 JSON schemas.
Private originals, photographer caches, local fitted LUTs, environments and
machine-specific configuration are excluded from this release.

Download the ZIP and follow README. `SHA256SUMS.txt` verifies the uploaded ZIP.
Separate notices cover third-party LUTs, public fixtures and showcase photos.
