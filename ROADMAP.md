# Roadmap

## v1.0.0

Local MCP grading, photographic skills, ready-to-use LUTs, optional statistical
fitting and four independently graded showcases. Normal use requires no training.

## Next: dehazing

- Separate OpenCV processing tool and dehazing skill within MCP → Tools.
- Distinguish unwanted haze from intentional atmospheric depth.
- Evaluate color casts, noise, halos and sky transitions at preview strengths.
- Preserve originals and the existing grading interface.

## Next: masked grading

- Explicit spatial masks, orientation/dimension checks and feathering.
- Local exposure/color operations with documented encoding and compositing.
- Mask previews and independent candidate output paths.
- Evaluate edge artifacts, subject/sky conflicts and invalid inputs.

## Later exploration

Scene-aware LUT selection, broader independent-photo validation, color-managed
inputs, style matching, optional vision models and better strategy generation.
These are development directions, not released features.
