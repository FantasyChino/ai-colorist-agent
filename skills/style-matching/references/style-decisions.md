# 根据照片与意图选择调色风格

检索与整理日期：2026-10-01。场景表是原创决策框架，不是大师预设或自动分类器。
由当前 Codex 多模态模型直接看图判断，不依赖 `analyze_image`，不另建 Agent 或调用模型 API。

## 1. 风格选择次序

1. **用户意图**：已有参考、纪实需求、商业目标或明确偏好优先。
2. **原片条件**：受光、已有黑白关系、纹理信息、色彩分离、媒介和渲染状态。
3. **保留项**：列出不能牺牲的主体、肤色、光源、云层、真实颜色或剪影。
4. **候选方向**：先选最多两种可解释方向，再决定是否需要 LUT。
5. **验证**：候选从原片生成，实际看图后决定，不能只凭 LUT 名称确认风格。

摄影类别只提供线索；同一幅人像既可自然、低调、明亮，也可高反差。
“电影”“胶片”“日系”“大师”不是充分执行指令，应拆成明暗分布、色彩关系与目标情绪。
不根据场景强制 LUT，不把低饱和或抬黑当默认专业答案。
此原则结合 Cullen Kelly 对 look 的意图和一致性讨论；具体场景取舍是本项目推导。[对比与 look 教程](https://blog.frame.io/2020/03/02/crafting-style-using-contrast-looks/)

## 2. 第一眼观察清单

| 观察项 | 要回答的问题 | 影响 |
| --- | --- | --- |
| 主体 | 视线先落在哪，是否符合意图 | 明暗/颜色分离优先级 |
| 光比 | 受光面与阴影差多少 | 新增对比的容忍度 |
| 黑位 | 建筑、头发、剪影能否锚定画面 | 是否允许抬黑或加密度 |
| 亮部 | 云、皮肤、光源有无梯度 | 曲线或 LUT 的亮端风险 |
| 原色 | 是否已有暖冷关系、环境光 | 是否应保留原有配色 |
| 肤色 | 是否与背景共享需调整的色相 | 全局 HSL 副作用 |
| 信息 | JPEG 是否已剪切或有强渲染 | 允许修改幅度与恢复边界 |

光比判断关注主体实际照明而非单一全图均值；参考 [Cullen Kelly 摄影光比](https://blog.frame.io/2023/07/24/how-professional-colorists-look-at-image-contrast-ratio/)。

## 3. 自然风光 / natural landscape

**适合意图**：保留地貌、天气和现场光线，以清晰真实的层次呈现景物。
**先看**：山体与天空分离、远景大气透视、植被绿是否天然偏暖/偏冷。
**调色方向**：保留白点与自然黑位；原片扁平时少量增加中间调分离；颜色先保留再处理问题色。
**LUT 候选条件**：来源清楚、兼容输入、轻度自然 palette；不能因文件叫“Landscape”便自动采用。
**拒绝信号**：植被变荧光、天空变青紫、远山全被抬平，或者所有阴影失去光照方向。
**能力边界**：若天空和山体需要不同亮度处理，当前无空间 mask 时不能声称局部完成。

## 4. 落日与蓝调 / sunset, blue hour

**适合意图**：保留太阳方向、暖天空与冷暗部之间的分离，体现由亮到暗的时间感。
**先看**：暖亮部是否已漂亮、云层是否有梯度、前景是否为有意剪影。
**调色方向**：先保留对比与黑位；优先防止天空被增曝光/增饱和剪切；只在主体需要时谨慎打开暗部。
**LUT 候选条件**：亮端保留较好且不破坏原冷暖关系；可完全不使用 LUT。
**拒绝信号**：天空橙色堆积、建筑黑变灰、白点暗淡、所有云挤在同一亮度，或暖色调覆盖全图。
**本项目 input 的约束**：上一版被用户评价为发灰、层次差；下一版应保留原片的黑位和天空，而非继续默认降全局对比。
**能力边界**：JPEG 已白的天空不能真实找回；全局 HSL 调暖色可能同时改建筑和云。

## 5. 城市夜景 / city night

**适合意图**：让城市光源成为焦点，同时保留暗场与空间深度。
**先看**：霓虹或路灯是否已通道剪切、暗区有无可用纹理、混合光是否为场景特色。
**调色方向**：保留真正暗区，谨慎控制鲜艳光源；先确定主体后决定整体是否需要更亮。
**LUT 候选条件**：冷暗部/暖灯光方向与现场相符，强度低，不能产生明显肤色偏绿或亮源断层。
**拒绝信号**：全局提亮成灰天、灯牌文字消失、青橙覆盖所有物体、暗部噪声变成视觉主角。
**能力边界**：无亮度限定/局部 mask 时无法只保护灯牌或只提亮人物，选择较小幅度。

## 6. 自然人像 / natural portrait

**适合意图**：人物可读、肤色与现场光一致，面部结构自然。
**先看**：脸的受光面与阴影、肤色相对中性物和背景、头发/衣服的明度分离。
**调色方向**：先检查脸部明度，保留微妙光比和皮肤亮部；背景问题色有必要才调整。
**LUT 候选条件**：兼容输入、肤色稳定且对比适当；“Portra”名称不能保证真实模拟或合适肤色。
**拒绝信号**：皮肤过橙/绿/粉、亮面塑料感、所有人物统一橙色、发丝阴影剪切。
**能力边界**：皮肤和背景共享橙/红时，全局 HSL 无法语义保护人脸；应减量或弃用该调整。
**原则**：高光柔和与抬黑是独立选择；人像不自动要求低对比，也不自动要求整体偏暖。

## 7. 高调 / high key

**适合意图**：轻盈、明亮、白色背景与高亮主体，仍有轮廓和材质。
**先看**：是否确为亮调设计，皮肤与白衣、主体边缘是否仍有区别。
**调色方向**：维持明亮中间调；保留关键纹理与少量形体阴影，不为了直方图黑端强行压暗。
**LUT 候选条件**：轻量亮调 look，不截断白衣/肤色梯度；对比强 LUT 通常需要拒绝或显著减量。
**拒绝信号**：轮廓消失、肤色亮面变纯白、为“胶片”把白色压灰。
**能力边界**：没有 RAW 信息恢复时，已剪切的白色布料不能被找回。

## 8. 低调 / low key

**适合意图**：暗环境中呈现关键受光面，让亮点与阴影表达情绪。
**先看**：主体是否仍清楚，最暗区域是否有意留黑，光源与受光面是否连贯。
**调色方向**：以主体受光面为曝光参照；保留深阴影，不以“暗”为由全局提亮。
**LUT 候选条件**：具有暗端分离且不把主体重要结构压黑的 look；无需把全部暗部染蓝。
**拒绝信号**：灰雾覆盖全图、人物与背景混为黑块、强色在阴影中意外抢主体。
**能力边界**：若仅局部脸需要提亮，不能用全局曝光自称实现 dodge。

## 9. 纪实 / documentary

**适合意图**：忠实表达人物、地点与光线，不使风格压过信息。
**先看**：原光色与曝光是否妨碍叙事，观者能否读到关键动作与环境。
**调色方向**：有限校正，保持可信颜色和完整层次；不要把“真实”理解成全局低饱和。
**LUT 候选条件**：如果确有系列一致性需求，尝试轻量 neutral look；单幅图可能无需 LUT。
**拒绝信号**：青橙先于故事、肤色变形、关键环境颜色失真、重要暗部动作消失。
**能力边界**：局部复杂混光无法用一个白平衡或一个 HSL 值真实解决。

## 10. 褪色 / matte

**适合意图**：用户明确要褪色、纸感或低反差视觉，而非默认怀旧标签。
**先看**：主体轮廓是否足够清晰、原片有没有可保留的中间调与亮部层次。
**调色方向**：若确需抬黑，幅度保守；中间调仍有分离，亮部仍有生命力，不同步机械压暗白点。
**LUT 候选条件**：已验证不过度抬黑和削白的 faded look；从低强度开始比较。
**拒绝信号**：灰罩、颜色脏、亮部塌陷、人物或建筑失去结构。
**原则**：matte只是风格选择之一；胶片还涉及曝光响应、颜色密度和显示渲染，不等于褪色。

## 11. 黑白 / black and white

**适合意图**：让形状、明暗、纹理与动作成为主要表达。
**先看**：去除色彩后主体是否仍可辨认，原片不同颜色是否映射成相近灰度。
**调色方向**：先评估灰度关系，再选择对比；柔和、硬朗、高调、低调黑白都是独立方向。
**LUT 候选条件**：兼容输入且黑白映射有层次；黑白不是对任意原图全局去饱和即可成功。
**拒绝信号**：主体与背景重叠、天空纹理没了、皮肤灰值不自然、所有黑白端点被挤压。
**能力边界**：本项目若只有 HSL 或 LUT，不承诺 Lightroom B&W Mixer 的按色灰度混合能力。
专业 B&W 可以按原始色彩分别控制灰值，见 [Julieanne Kost Lightroom 技巧 PDF：Black & White Conversions](https://jkost.com/blog/wp-content/uploads/2024/02/2024_LrC_v13_Shortcuts.pdf)。

## 12. LUT 候选的场景备注格式

记录 `名称 / 来源 / 授权 / 输入输出空间 / 实测倾向 / 适用意图 / 避免场景 / 试验强度 / 预览证据`。
厂商解释与本地视觉实测要分开：文件叫“Warm”不证明所有人像适用，叫“Film”不证明物理胶片模拟。
强度范围是本项目候选试验起点，不是大师统一数值；技术转换不能靠减强度解决空间错误。
同一 LUT 在雾景、夕阳、肤色与霓虹上可能完全不同，至少检查一个目标场景与灰阶/强色风险。
查不到输入空间的 LUT 标记不确定；查不到授权的 LUT 不纳入可分发库。
LUT不会识别主体、天空、材质或意图；使用决定来自模型观察和输出复核。[Cullen Kelly LUT 基础](https://blog.frame.io/2019/08/12/luts-101/)

## 13. 风格验收

- 先问“服务这张照片吗”，再问“像哪个风格”。
- 记录改动理由与应保留内容，避免只有形容词和预设名。
- 输出与原图比较，特别检查主体、白点、黑位、肤色和原本最漂亮的光色。
- 如果只是更亮、更灰或更有滤镜感却更难读，回退，不把强变化当作成功证据。
- 没有参考时以原片自然光色为起点；强风格应有明确意图和可查看候选。
- LUT 的空间条件、执行层边界与亮部保护规则见 `../../color-strategy/references/grading-foundations.md`。
