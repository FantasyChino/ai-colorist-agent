# v1.0 Ready Looks

这10个原创固定映射可用于不同照片，不需要训练。不是神经网络权重、摄影师官方配方或精确胶片模拟。它们使用 Lab 曲线、色度、阴影/亮部染色和色域压缩，编译成编码 sRGB 的 CUBE33。

| Catalog ID | 方向与候选场景 | 起点与拒绝信号 |
| --- | --- | --- |
| ac_amber_dusk | 暖亮部、冷暗部；黄金时段、暖旅行 | 0.65；过橙、白色染黄时减弱 |
| ac_coral_dusk | 珊瑚暖色；晚霞、柔暖场景 | 0.65；肤色偏红、紫色云层失真时拒绝 |
| ac_teal_gold | 青暗部、金亮部；城市、冷暖分离 | 0.65；阴影偏青损害物体颜色时减弱 |
| ac_vivid_travel | 较强反差和色度；旅行、丰富色彩 | 0.60；饱和色挤压、主体过艳时减弱 |
| ac_clean_landscape | 轻反差、轻色度；自然景物 | 0.65；变化不足可提高，但不以强度替代质量 |
| ac_olive_gold | 橄榄/金色方向；植被、暖自然 | 0.60；皮肤偏绿、植物失去分离时拒绝 |
| ac_urban_cool | 冷色、密度；城市蓝调、阴天 | 0.60；暗部堵塞、暖灯失去意义时拒绝 |
| ac_soft_editorial | 柔和反差、轻减色度；柔光、高调 | 0.65；已经发灰或需强反差的照片避免 |
| ac_neutral_density | 中性反差；纪实、形状和光影 | 0.70；暗纹理减少时减弱 |
| ac_silver_mono | 黑白、较强灰度反差 | 明确黑白意图时1.0；重要颜色承担叙事时避免 |

所有场景仅是筛选方向。先看原片，再使用 `list_looks → prepare_look → apply_color_grade`，打开输出检查。不要同时堆叠高对比和强 LUT。橙色区域的减弱规则只是颜色启发，不识别脸或保护所有肤色；阴影/亮部染色也不是局部蒙版。

公共测试样本在 `tests/fixtures/`，覆盖人像、静物、动物和夜景；`scripts/validate_looks.py` 可在本机生成40组候选。它们只作基础响应检查，不能代替视觉验收。用户认可的成片见 `docs/showcase.md`，使用逐图设计的配方。中性灰阶单调和端点保留不保证每个彩色区域无剪切，也不代表所有相机、肤色、题材与曝光条件。
