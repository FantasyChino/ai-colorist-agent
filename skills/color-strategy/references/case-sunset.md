# 回归案例：城市晚霞与剪影

原图：项目根 `demo/input.jpg`，5568×3712。模型直接观察原图；不是由像素统计生成策略。

## 应保留的摄影关系

暖色晚霞与偏冷山体、道路形成分离；树木和建筑的深黑锚点让天空发光。
天空有黄白亮区、橙色过渡和灰紫云层，不能为了降低数值反差把它们全部压成灰。
暗前景是逆光构图的一部分，不能仅因有黑像素就认定欠曝。

## 上次失败的控制

`contrast=low` 在当前工具中是以128为中心乘0.8：黑端约25、白端约229。
再对多个色相减饱和、提亮，会弱化原有暖冷和明暗关系。这不等于有选择地
保留高光或增加暗部细节，也不等于胶片感。用户反馈明确指出发灰、亮部
细节和对比度受损；后续不能沿用该起点或用上一版 JPEG 再叠加。

## 新库的实际预览

`scripts/preview_luts.py demo/input.jpg` 生成
`demo/lut-previews/contact-sheet.jpg` 和 `preview-report.json`。
原图缩至1200×800，8个候选由现有 `ColorPipeline` 从同一原片预览生成。
彩色候选为25%；明确标注的 Tri-X 黑白候选为100%，仅供风格对照，不能
在用户未要求黑白时自动选用。预览不是全分辨率成品验收。

最初预览可发现的细微差异（不构成可交付改善）：

- Portra160/400 提亮中间调，山体和天空的柔化并不必然优于原片。
- Provia/Superia 使暗部和云层带入额外色偏；交通标识、建筑和晚霞需一起看。
- Velvia 使暗部更密、晚霞更浓，但原图已有较浓的黄色，需要较低强度试验。
- Meridian 虽较少染中性色，也提亮中间调；“中性轴”不能保证摄影光比不变。
- Lowsun 进一步强化暖亮部/冷阴影；原有分离已明显，增加它未必有收益。
- Tri-X 改变了照片以晚霞色彩为重点的表达，不作为本次默认方向。

这些是对这张图片的视觉判断，不是整类照片的固定评分或 LUT 排名。
按用户提出的“保留亮部细节和对比度”，起点应为 `exposure=0`、
`contrast=medium`、`black_point=normal`，然后只做有可见收益的小幅调整。
无 LUT 也必须保留为候选，不能为了证明插件有效而强行改变原片。

## 回归验收

对照原片检查云层梯度、黄白亮区分离、建筑黑位、山体与道路深度，以及
车灯和信号灯的颜色边界。放大检查最终 JPEG，再判断是否值得保留。
当前工具没有局部 mask、高光恢复、软肩或 ICC 转换，不得声称用它恢复了
原 JPEG 未记录的天空细节。

## 用户反馈后的重新验收

用户指出：除100% Tri-X黑白外，看不出彩色候选的变化。重新对照九宫格、
同尺寸原片和单图后，确认这组彩色候选没有清楚改善天空纹理、山体分离
或道路可读性；不能推荐一张作为“已经调好”的赢家。

实际策略为曝光0、中等对比、正常黑位、无HSL，只混入25% LUT。前三项
均为中性控制，因此尚未针对这张照片执行有目标的基础调色。彩色候选
相对同尺寸原片的平均通道绝对差仅约1.33–2.92/255；这证明映射执行了，
不证明质量改善，也不替代视觉判断。Tri-X转黑白的显著变化同样不是改善证明。

这组图应记为格式/兼容性与低强度风格预览。先前把它作为调色能力的展示
不充分。后续必须提出可检查的视觉目标，选择实际能改变该关系的控制，
再以正常观看和局部对照验收。保守强度不是固定成品强度；提高强度仅用于
了解候选响应，不能替代判断或以牺牲天空/黑位来证明“做了调整”。

## 继续后的实际调色

目标收敛为：打开可用的道路/车身低中间调，保留深树木、建筑黑位与晚霞光色。
现有 contrast 选项过粗，HSL又会跳过 S<50 或 V<50 的区域，所以生成了
本项目原创的照片专用 creative CUBE，继续通过现有 LUT 引擎和 MCP 应用。
它是编码 RGB 的明暗/色度映射，不是空间 mask、线性曝光或高光恢复。

候选见 `demo/grading-review/`：A为明暗调整，B额外整理色彩，C为65% Velvia。
A/B道路与车身可读性有可见收益；B的附加色彩没有足够收益，C让道路更暗。
选择A，并修订为v2以减少对云层中间调的提亮。

实际选用 `assets/luts/custom/city_sunset_tone_v2.cube`，曝光0、对比medium、
黑位normal，由原生 `apply_color_grade("demo/input.jpg", strategy)` 输出
5568×3712 `output.jpg`。策略保存在 `demo/grading-review/selected-strategy.json`，
成品副本为 `demo/grading-review/output-tone-v2.jpg`。生成代码和CUBE旁的
provenance保存锚点及来源；它没有借用外部LUT表，也不宣称大师预设。

验收：中下部路面、横穿车辆和远处车流的低中调更容易辨认；树木、建筑
仍为暗部锚点；天空黄白、橙色、灰紫过渡保持连续。整图和局部对照未见
明显新增灰罩、色偏或断层。改善集中在层次可读性，不是强烈风格重塑。
灰阶检查为单调、黑0/白255，中性色通道差最多1码。原片SHA-256不变。
旧output已备份；整图、道路和天空的对照位于同一review目录。

这只是对这张原片的已查看结果，不自动推广到其他曝光、场景或编码输入。
