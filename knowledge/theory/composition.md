# 构图与调色的条件式关系

本文件提供观察线索，不从构图类别自动推出风格、对比值或 LUT。
由 Codex 直接看原图，先找视觉焦点与空间结构，再决定颜色与明暗是否需要改变。

## 主体位置与平衡

- 居中、对称可以表达稳定或仪式感，也可以表达压迫；不能单独决定“柔和人像”风格。
- 三分位置、不对称可以增加方向感，但是否有张力取决于人物姿态、空间与内容。
- 调色后检查视线是否仍落在目标主体，而不是被更亮或更饱和的背景吸引。

## 留白与简化

大面积留白可以表现安静、尺度、孤独或开放；不能一律等同日系、低对比和低饱和。
若原片靠深黑主体与亮背景形成简洁构图，应保留这种关系，而不是用抬黑削弱轮廓。
减少背景颜色干扰可以帮助主体，但只有在共享色相副作用可接受时才用当前 HSL。
没有位置 mask 时，不能声称已单独压背景、提主体或实现 dodge/burn。

## 深度与层次

前景、主体、背景的重叠、尺寸、清晰度、明暗和冷暖都可能制造深度。
远景灰雾可能是大气透视，不能无条件“增强对比”；前景剪影也可能是主动构图。
若画面已依靠暖天空/冷暗部或主光/背光清晰分离，先保留，再考虑微调。
色彩关系可以强化空间，但全局染色或统一抬暗可能抹掉原有分层。

## 选择风格与实施

先描述“方向 → 图像证据 → 应保留内容 → 拒绝信号”，不编造“此构图必属某大师”的概率。
构图、照明、镜头、运动和布景的效果不能全部靠一个 LUT 再现。
当前 LUT 是对 RGB 值的全局映射，无法识别画面位置或构图元素。
真实 ID lumix_meridian 可作轻量日光风格候选，pat_kodak_tri_x_400 仅在用户要黑白且主体灰度分离足够时考虑；都不因构图自动采用。
看输出与原图比较主体轮廓、重要亮部、黑位及空间深度；副作用大于收益时回退。
